Self-hosted messaging
Fluenta Lightweight communities, DMs and voice

Connect your server

Fluenta is open source and runs on a server you or a friend hosts. Enter its address to sign in, create an account and start chatting. You can switch servers later in Settings.

I do not have a server yet

Run the open-source server on any machine with Node 24, then point this app at it. The first account you create becomes the server founder. 

git clone https://github.com/itriedcoding/Fluenta
cd Fluenta && npm ci && npm run build:web
APP_ORIGIN=https://chat.example.com npm start

Full self-hosting notes live in the README. On a phone you can also use a LAN address such as http://192.168.1.10:8787.
